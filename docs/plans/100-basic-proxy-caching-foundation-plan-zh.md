# 基础代理与持久化缓存底座方案 (Basic Proxy & Caching Foundation Plan - Plan 100)

## 1. 方案背景与阶段目标 (Background & Goals)

在项目初期阶段，核心诉求是构建一个轻量、高效且免侵入的通用下载代理底座，解决多客户端重复拉取公网资源时的带宽浪费与网络延迟问题。

Plan 100 阶段聚焦于打通代理数据流与磁盘缓存基础能力，确立以下阶段目标：
1. **透明代理转发**：提供对 HTTP、HTTPS 以及 FTP 资源的透明中继与流式传输，完整透传 HTTP 状态码与响应头元数据；
2. **本地文件持久化缓存**：建立冷请求双写落盘、热请求直接命中本地文件的基础存储能力；
3. **域名规则转发支持**：支持根据目标 Host 规则进行网关转发与前置中继；
4. **跨平台安全路径转换**：解决不同操作系统文件系统（Windows、Linux 等）对特殊字符限制及超长路径问题，防止路径穿越风险。

## 3. 核心机制与架构沉淀 (Architecture & Core Mechanisms)

### 3.1 透明路由与流式中继
客户端通过代理服务请求目标资源时，代理层解析目标协议与主机地址，以流式管道方式将上游数据边下载边写入下游客户端，无需在内存中预载完整资源，保障低内存开销。

### 3.2 安全缓存路径规范
为解决 URL 中包含特殊字符（如冒号、问号、通配符）以及超长 URL 导致的磁盘落盘失败问题，设计了基于安全字符白名单与摘要哈希的安全文件路径映射机制：
- 非法字符统一转义或规约；
- 超长路径结合摘要哈希压缩长度；
- 严格规避相对路径穿越符（`..`），保障磁盘读写安全性。

### 3.3 演进与替代关系
在 Plan 100 阶段独立实现的域名转发规则，后续在 Plan 300 阶段由 Feature 304（统一代理配置系统）进行了标准化整合与语法升级，确立了集中式的单一真理源配置管理模式。
