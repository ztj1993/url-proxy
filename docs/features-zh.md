# url-proxy 支持的特性列表

## 核心代理能力

- 基础透明代理转发
- 本地文件缓存
- 跨平台安全缓存路径生成
- 标准 HTTP 正向代理协议（CONNECT 隧道）
- 条件请求与 304 快速协商透传
- Range 请求与 206 断点续传
- 并发下载合并（Request Coalescing）
- 空闲超时自动清理

## 路由与配置

- 统一代理配置文件系统（`proxy.conf`）
- 域名规则转发
- 路径短别名路由与动态重写
- 可配置免缓存规则（白名单/黑名单仲裁）

## 响应体处理

- 流式动态响应体重写引擎
  - MIME 类型匹配
  - 文件后缀匹配
  - 自定义类型别名（`type` 指令）

## 生态集成

- **APT**
  - 路径短别名模式
  - 标准正向代理协议模式
- **Alpine**
  - 路径短别名模式
- **PyPI**
  - 简单索引（Simple Index）动态透传
  - Wheel / 源码包持久化缓存
  - 绝对链接自动重写（HTML + PEP 691 JSON）
- **npm**
  - 包元数据动态透传
  - Tarball 持久化缓存
  - 元数据中 Tarball URL 自动重写
- **Docker / OCI**
  - Registry v2 协议中继
  - 镜像清单动态透传
  - 镜像分层（Blobs）持久化缓存
- **Rust Cargo**
  - 稀疏索引（Sparse Index）动态透传
  - `config.json` 下载端点自动重写
  - `.crate` 包持久化缓存
- **Go / Maven**
  - 路径短别名模式

## 架构与工程分层

- **代码库模块化与领域分层重构 (Feature 321)**
  - 核心业务逻辑解耦拆分为 7 大 `internal` 领域子包
  - 任务池与调度器面向对象封装，彻底消除包级全局变量与全局锁
  - 根目录保留轻量级主入口，全工程接入原生 Go 单元测试闭环
