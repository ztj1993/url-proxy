# url-proxy 支持的特性列表

## 核心代理能力

- 基础透明代理转发
- 本地文件缓存
- 跨平台安全缓存路径生成
- 标准 HTTP 正向代理协议（CONNECT 隧道）
- 条件请求与 304 快速协商透传
- Range 请求与 206 断点续传
- 并发下载合并（Request Coalescing）
- 空闲超时自动清理

## 路由与配置

- 统一代理配置文件系统（`proxy.conf`）
- 域名规则转发
- 路径短别名路由与动态重写
- 可配置免缓存规则（白名单/黑名单仲裁）

## 响应体处理

- 流式动态响应体重写引擎
  - MIME 类型匹配
  - 文件后缀匹配
  - 自定义类型别名（`type` 指令）

## 生态集成

- **APT**
  - 路径短别名模式
  - 标准正向代理协议模式
- **Alpine**
  - 路径短别名模式
- **PyPI**
  - 简单索引（Simple Index）动态透传
  - Wheel / 源码包持久化缓存
  - 绝对链接自动重写（HTML + PEP 691 JSON）
- **npm**
  - 包元数据动态透传
  - Tarball 持久化缓存
  - 元数据中 Tarball URL 自动重写
- **Docker / OCI**
  - Registry v2 协议中继
  - 镜像清单动态透传
  - 镜像分层（Blobs）持久化缓存
- **Rust Cargo**
  - 稀疏索引（Sparse Index）动态透传
  - `config.json` 下载端点自动重写
  - `.crate` 包持久化缓存
- **Go / Maven**
  - 路径短别名模式

## 架构与工程分层

- **代码库模块化与领域分层重构 (Feature 321)**
  - 核心业务逻辑解耦拆分为 7 大 `internal` 领域子包
  - 任务池与调度器面向对象封装，彻底消除包级全局变量与全局锁
  - 根目录保留轻量级主入口，全工程接入原生 Go 单元测试闭环

## 系统稳定性与缓存治理 (Stage 330)

- **非 200 响应脏缓存防污染与纯流式透传 (Feature 331)**
  - 严格仅在 200 OK 时允许临时文件创建与原子重命名，彻底杜绝 4xx/5xx 错误页污染磁盘缓存
  - 非 200 错误正文通过 `io.Copy` 纯流式透传给客户端，保持零堆内存常驻并即刻释放连接
  - 下载管理器底层 `TryRename` 硬性断言熔断，非 200 强制销毁临时文件拒绝重命名
- **基于磁盘文件与 mtime 的时效缓存与条件更新 (Feature 332)**
  - 动态元数据 100% 磁盘落盘存储，彻底消除堆内存堆积与 OOM 隐患
  - 利用文件系统修改时间（`mtime`）进行零内存开销保鲜期判定（`time.Since(mtime) < TTL`）
  - 过期自动向上游发送 `If-Modified-Since` 条件请求，304 响应调用 `os.Chtimes` 零流量 touch 续期
  - 源站网络故障或 5xx 时自动执行 `STALE-FALLBACK` 容灾降级，保障高可用
- **磁盘 TTL 资源并发刷新与请求合并 (Feature 333)**
  - 过期探测与重验证请求接入并发下载合并管理器，同 URI 严格合一为单一出向请求
  - 广播共享 304 续期、200 更新流式消费与故障降级，彻底杜绝源站击穿（Revalidation Stampede）
  - 上游出向请求与客户端连接生命周期解耦，首个客户端中途断连不影响其余等待者
- **上游 HTTP 连接池调优与超时加固 (Feature 334)**
  - 全局连接池提升至 `MaxIdleConns: 1000`，单主机空闲连接上限提升至 `MaxIdleConnsPerHost: 100`（50 倍提升）
  - 显式配置 `ResponseHeaderTimeout: 30s`，彻底杜绝上游假死导致的协程无限挂起
  - 传输层封装于实例级别，消除对标准库全局 `http.DefaultClient` 的隐式耦合
- **CONNECT 隧道滑动空闲超时自愈与半关闭回收 (Feature 335)**
  - 为 HTTPS CONNECT 隧道双向封装滑动空闲超时（默认 5 分钟），静默超时自动双向回收 Socket
  - 支持 TCP 半关闭（`CloseWrite`）优雅传递，消除单向 EOF 导致的数据截断风险
  - 劫持连接全生命周期托管与协程优雅同步退出
- **启动时孤儿临时文件扫描与自愈清理 (Feature 336)**
  - 精准基于纳秒纯数字时间戳特征（`.<18~20位数字>`）识别临时文件，零误杀正常制品
  - 启动阶段后台异步扫描缓存目录树，安全清理修改时间超过 1 小时的崩溃残留孤儿临时文件
